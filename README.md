# Punto Fiscal - páginas públicas

Sitio público de **Punto Fiscal Autónomos** y **Punto Fiscal: nómina y Renta**, dos apps para iPhone (España). Autónomos: calendario fiscal con avisos y hucha para el modelo 130 y 303. Nómina y Renta: sueldo neto, finiquito, despido, paro, baja médica y simulador de la Renta. Sin cuentas; el servidor de punto-fiscal.com hace los cálculos con los datos del formulario y no los guarda.
